# PangenomeEngine

Pangenome construction and analysis engine for core/accessory genome partitioning, variation graph building, and open pangenome characterization.

## Features

- Core, accessory, and unique genome partitioning across strains
- Pangenome growth curve fitting and openness classification
- Variation graph construction for structural variant representation
- Gene presence/absence matrix analysis and clustering
- Functional enrichment of core vs. accessory gene sets

## Results

100 genomes; Core=18.7%, Accessory=62.3%, Unique=19.0%; Open pan-genome

## Usage

```bash
pip install numpy scipy matplotlib
python pangenome_engine.py
```
